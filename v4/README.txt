ROCÍO BLANCO — WEB DEFINITIVA / BASE DE PRODUCCIÓN

Esta versión reemplaza la lógica de demostración anterior y deja la web preparada para producción.

ANTES DE PUBLICAR:
1. Sustituir la fotografía placeholder por las fotos profesionales reales de Rocío.
2. Configurar email, WhatsApp y sistema real de reservas.
3. Conectar el formulario a un proveedor seguro y con el tratamiento de datos correspondiente. NO usar localStorage para datos de pacientes.
4. Confirmar tarifas, duración y condiciones.
5. Completar aviso legal, privacidad, cookies y datos profesionales/colegiación con revisión adecuada.
6. Añadir favicon/OG image definitiva si se desea.
7. Configurar Search Console, sitemap.xml, robots.txt y analítica solo después de decidir la herramienta y su consentimiento.
8. Revisar textos clínicos y servicios con Rocío antes de publicar.

La web no guarda formularios en localStorage ni exporta datos del navegador.
